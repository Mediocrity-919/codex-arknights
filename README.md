# Codex Arknights

为 Codex Windows 桌面客户端提供明日方舟风格启动动画、静态与动态壁纸、独立构图和播放队列的社区伴随程序。

**本项目免费，以个人兴趣、学习和社区分享为目的，不以盈利为目的。** 本项目与 OpenAI、鹰角网络及其关联公司没有官方合作或隶属关系，也不是官方插件市场中的主题扩展。

当前版本：**0.12.0 · Windows 桌面测试版**。

[下载测试版](https://github.com/Mediocrity-919/codex-arknights/releases/tag/v0.12.0) · [反馈问题](https://github.com/Mediocrity-919/codex-arknights/issues) · [详细使用说明](docs/BETA-GUIDE.md)

## 功能

- 启动动画与壁纸接入；保留客户端原有聊天、附件和工具操作。
- 静态背景与干员／时装立绘分层组合，各自调整缩放和位置；完整活动壁纸可直接使用。
- 按八种职业、干员、时装／晋升立绘浏览动态壁纸，自动顺序播放该套全部动作。
- 壁纸中心与浮动调节面板同步，支持透明度、明暗遮罩和磨砂设置。
- 保存构图、多队列管理、指定加入目标、循环播放。默认静态停留 60 秒、动态播放整套 2 遍，可自行调整。
- 按需获取单张图片或一套动态皮肤；支持进度、重试、取消和删除，无需下载全部素材。
- 原片／可选 4K、性能回退、双视频槽预载与有效帧保护；同套动作可按需建立连续播放缓存，默认磁盘预算 2 GiB。

## 使用环境

| 项目 | 要求与范围 |
| --- | --- |
| 系统 | Windows x64，建议 Windows 11 x64；macOS、Linux、ARM 未验证 |
| 宿主客户端 | 当前适配 Windows 的 `OpenAI.Codex` 应用包，程序名可能是 `ChatGPT.exe` 或 `Codex.exe`；开发实测版本为 26.1016.8622.0。不是所有名为 ChatGPT 的客户端或网页版均适用 |
| 基础组件 | Windows PowerShell 5.1、.NET Framework 4.x；Windows 发布包自带 Node 运行环境 |
| 启动动画 | 需要 Microsoft Edge WebView2 Evergreen Runtime；包内包含 SDK 依赖，不等于系统 Runtime。不可用时提供简化启动回退 |
| 联网 | 获取素材时需要网络，已下载素材可在本地播放 |
| 普通图片／MP4 | 不需要 Python 或超分环境 |
| FFmpeg | 可选；HLS 下载及连续播放缓存需要配置。没有它时，已有 MP4 仍可分段播放 |
| AI 4K | 可选本机派生处理，需要另配 NVIDIA CUDA、Python/PyTorch、FFmpeg 和模型；普通用户建议先使用原片 |

通过本机调试接口接入识别到的客户端窗口。客户端升级可能改变界面结构；结构不匹配时停止换肤并保留原界面。当前只向一个验证过的主窗口接入，不承诺未来版本自动兼容。

## 下载与运行

1. 在 [Releases](https://github.com/Mediocrity-919/codex-arknights/releases) 下载 **`codex-arknights-0.12.0-windows-x64.zip`**。GitHub 自动生成的 Source code 是源码，不是可直接运行的完整包。
2. 解压到独立、可写目录，例如 `D:\Apps\CodexArknights`；请完整解压，不要直接在压缩包内打开。
3. 首次使用前保存工作并正常退出客户端，然后双击 **`ARK启动Codex.cmd`**，或运行 **`dist/ArkBoot.exe`**。
4. 进入客户端后打开左侧壁纸入口，在壁纸中心选择内容并下载、应用。

**ArkBoot.exe 是启动器，不是单文件安装包。** 它需要同目录体系中的脚本、运行环境和启动动画文件，因此请保留整个解压目录。初次运行使用包内原创默认背景；发布包不含游戏素材库、4K 视频或模型。

## 安装、更新与卸载

- 双击 **`安装.cmd`**：默认安装到 `%LOCALAPPDATA%\ArkWorkspace`，创建独立的“Codex 壁纸版”桌面入口，不需要管理员权限。
- 默认不替换原客户端入口。如需绑定现有快捷方式，在解压目录执行以下命令；脚本会备份识别到的原入口：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Theme.ps1 -BindExistingShortcuts
```

- 恢复原快捷方式：运行 **`恢复原启动入口.cmd`**。
- 恢复客户端原界面：使用主题面板的恢复按钮，或按 `Ctrl + Shift + Backspace`。
- 更新：备份安装目录的 `.local`，解压新版本后运行安装脚本安装到原目录。使用自定义目录时指定 `-Destination`。个人数据会保留；测试版没有联网自动更新。
- 卸载：运行安装目录中的 **`卸载.cmd`**，恢复绑定入口并删除未修改的程序文件，默认保留个人设置与素材。完整清理的高级参数见 [使用说明](docs/BETA-GUIDE.md)。

不要把可移植目录放进只读位置。移动安装目录前先恢复快捷方式，在新位置重新安装。

## 素材、画质与播放队列

在壁纸详情点击“下载 / 管理素材”，选择原片或 4K。4K 是可选的本机派生处理，并非官方原生 4K；已有本地 4K 可直接使用。工具可在资源中心或 `配置视频工具.cmd` 中配置。获取依据见 [背景资源获取](背景资源获取.md)，AI 环境见 [资源工具说明](tools/resource-fetcher/README.md)。

“已存组合”保存背景和干员的构图，方便手动重用；“播放队列”用于轮播。同一队列的静态干员组合共用背景及背景构图，每个干员的位置独立，完整壁纸和动态视频独立播放。全局透明度、遮罩等设置不属于组合。具体操作见 [使用说明](docs/BETA-GUIDE.md) 和 [队列说明](docs/QUEUE-V010.md)。

资源目录仅含来源与文件元数据。链接可能变更，下载失败时可重试或反馈；获取说明不代表取得素材再分发授权。

## 测试版已知限制

- 已完成核心测试、隔离视频交接检查和便携安装／卸载检查。开发环境约 27 分钟真实播放采样没有检出全黑画面，但期间主题接入中断，原因尚待排查；不能据此承诺所有设备无闪屏。
- 完整冷启动、不同机器、多屏／DPI 和未来客户端升级仍需实机验证。保存工作并正常退出客户端后可运行 `冷启动验收.cmd`。
- 附件窗口与其他应用被遮挡的问题，已修复启动交接遗留置顶状态，并由用户确认恢复；遇到问题请先恢复原界面。
- 自动降级只能帮助缓解高负载，不保证任意硬件播放全部 4K 素材流畅。

验证边界见 [0.12.0 验收记录](docs/PLAYBACK-V012-VERIFICATION.md)。反馈请附系统、客户端版本、壁纸名称和复现步骤；**不要公开 `.local`、个人聊天、带认证参数的本地地址或完整日志目录**。

## 开发与构建

```powershell

```
