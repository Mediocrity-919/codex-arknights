# Codex Arknights 0.12.6 · Windows Beta

免费、非盈利的社区桌面伴随程序。

## 新内容

- **全新启动动画**：主题为“罗德岛终端接入 Codex”。Codex 的 `>_` 提示符碎裂后拼合成源石晶体，随后展开干员档案，最后以斜切面板进入客户端。加载进度与真实启动阶段同步，支持 Esc 跳过和“减少动画”。
- **自动获取新壁纸**：启动后在后台检查官方动态皮肤和 PRTS 立绘的新增内容，默认每天一次，可在“素材管理 → 自动获取新壁纸”改为每周或关闭。新内容直接出现在壁纸库并带“新”标记，可按“最新加入”排序。只获取目录和封面，视频仍按需下载。
- **4K 组件一键安装**：素材管理的“视频处理组件”可一键安装 FFmpeg（约 110 MB），或完整 4K 组件（独立 Python、PyTorch CUDA、FFmpeg 和模型，约 2.7 GB）。安装前检测显卡与磁盘空间，过程可取消、可续传，完成后先用显卡试运行再启用。组件放在 `.local/tools`，不改动系统环境，可随时删除。NVIDIA 驱动需自行安装。

## 升级

下载 **codex-arknights-0.12.6-windows-x64.zip** 并完整解压。保存工作、正常退出客户端，备份安装目录 `.local` 后运行新包 `安装.cmd` 安装到原目录。个人素材、配置和已手动配置的视频工具会保留。

普通图片、MP4 和原片下载不需要 Python。4K 生成仍是可选的本机派生处理，并非官方原生 4K。
