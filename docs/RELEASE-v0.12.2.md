# Codex Arknights 0.12.2 · Windows Beta

免费、非盈利的社区桌面伴随程序。

## 本次修复

- 启动就绪检测改用轻量接口，避免遍历整套素材库导致超时；短暂网络超时会重试，避免重复创建主题助手。
- 修复活动与启动器背景下载提示“素材来源未获允许”，同时校验整个公开目录的图片、视频和封面来源。
- 下载跟随现有 Windows 手动系统代理或 HTTP_PROXY／HTTPS_PROXY，未配置时直连；本地主题连接保持直连。
- 新电脑可见壁纸卡片自动获取封面，每次最多两张，下载后自动更新卡片。

## 下载与更新

下载 **codex-arknights-0.12.2-windows-x64.zip** 并完整解压。包内包含 `dist/ArkBoot.exe` 和 Node 24.14 运行环境，不能只复制 EXE。使用 Windows x64 和已安装的 OpenAI.Codex 客户端。

已安装用户：保存工作并正常退出客户端，备份安装目录 `.local`，然后运行新包 `安装.cmd` 安装到原目录；自定义安装目录请使用安装脚本的 `-Destination` 参数。个人素材和配置会保留。

便携用户：使用完整新包，保留个人 `.local` 和素材目录；不要只更新启动器。之后双击 `ARK启动Codex.cmd`。旧下载任务可在更新后点击重试。

发布包不包含游戏素材库，壁纸按需下载。完整操作见仓库 README；校验值见 checksums-0.12.2.json。
