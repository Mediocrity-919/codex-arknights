# 0.12.0 动作连播优化验收

日期：2026-10-26。功能、隔离回归及安装验收已通过。真实客户端取得约 27 分钟自然播放样本；因主题接入中断，没有完成原定 30 分钟连续验收。用户决定本轮以 27 分钟为准，后续自行实测，不再延长测试。

## 真实客户端结果

在已有队列中自然播放约 27 分钟，观测到 48,819 个视频帧回调、79 次逻辑动作/循环/壁纸变化，其中 73 次进入连续缓存中的动作节点；接缝附近复合采样 2,223 次，没有检出全黑画面，采样错误 0 次。实际检查到了 3840×2160 连续缓存播放。报告：`test-results/native-seams-soak-27min-interrupted.json`、`test-results/native-quality-during-soak.json`。

接入退出的完整原因尚未确定，不能把本次记录写成完整 30 分钟通过。验收脚本已补充接入中断的明确判断，避免状态缺项时抛出模糊异常。结束后恢复了原壁纸选择，最终后端更新后重新接入，未重启 Codex 客户端。后续重点由用户观察长时间播放及日常模块切换。

## 已完成的检查

- Node 测试 17 项通过：包括原片不变、连续缓存帧数、异常边界帧、缓存持久化、主动取消/自动取消区别、重建时旧文件保护、相同缓存复用、容量淘汰和使用结束后的延迟清理。
- 当前队列四套真实官方皮肤，原片与 4K 各一份，共八份连续缓存通过无重编码构建、帧数与总时长核验及接缝解码检查。合计 1,397,249,363 字节（约 1.30 GiB），在默认 2 GiB 预算内。报告：`test-results/playback-cache.json`。
- 隔离浏览器完成 110 次三动作/四动作自然交接，采集 2,733 张合成截图，检出黑屏 0 张。包含下一动作延迟 1.7 秒、暂停恢复及构图修改保留预载。交接等待实际帧与缓冲就绪的 P95 为 84ms，最大 84ms；可见视频帧回调最大间隔 117ms。这是小尺寸合成视频的测试值，不代表所有 4K 硬件的性能。报告：`test-results/action-seams.json`。
- 原有四段本地视频及静态壁纸回归 9 组通过：循环、慢加载、快速换图、暂停恢复、失效素材保护、静态与动态往返、解码器销毁。报告：`test-results/media-results.json`。
- 壁纸页面和浮动面板回归 5 组通过，原生输入框保持挂载；资源中心缓存开关、容量与清理入口通过交互检查。
- Windows PowerShell 5 中的中文/空格路径便携安装、无系统 Node 启动、卸载、保留数据后重装通过；快捷方式按原始字节恢复通过。修复版本检查引号和 UTF-8 清单读取问题，真实桌面快捷方式及注册表没有参与测试。

## 资源边界

生产播放器常驻两个视频槽位；一个保护画布最多 1920×1080，像素内存上限 8,294,400 字节。当前真实窗口为 6,227,136 字节。手动预览另按需打开、关闭时释放；上述数量不包括用户主动打开的预览。

缓存构建串行、低优先级；不重新超分、不整段读入内存、不增加常驻解码器。缓存空间不足或工具不可用时回退分段播放器。测试过程验证用户队列与组合保留。

真实辅助进程在播放中期的工作集为 75.7 MiB、专用内存为 80.5 MiB；约 15 分钟后再次读取为 77.2 MiB / 86.0 MiB。这里只统计主题 Node 进程，不代表客户端、视频解码器或 GPU 的总开销，也不能仅凭两次读数证明没有长期内存增长。保护画布的尺寸及两个视频槽位在长测采样中保持有界。

## 验证范围

真实客户端检测只涉及壁纸视频/画布层，按图层顺序与透明度在小画布中复合取样；没有采集聊天内容，也不是 Windows 最终桌面帧缓冲逐帧录像。隔离浏览器的截图采样补充覆盖实际浏览器合成输出。两者均不等于所有驱动、硬件和窗口状态下的无闪屏保证。

已检查出原素材的少数异常边界黑帧，因此采用有效区间及片尾避让；正常暗场、动作姿态跳变不作 AI 修改。未提供异构显卡、多屏不同 DPI、最小化恢复和新客户端版本的全面认证。真实冷启动仍依照 `docs/BETA-GUIDE.md` 单独验收。
