# Codex Arknights 0.12.4 · Windows Beta

免费、非盈利的社区桌面伴随程序。

## 本次调整

- 最初四段视频均提供独立原片下载：邀月、纯烬艾雅法拉、黍 · 岁时、黍 · 闲庭。保留原始分辨率和帧率，不要求用户运行超分，也不放进程序安装包。
- 壁纸详情直接显示“下载原片”；其他官方动态皮肤另有“本机生成 4K”按钮。素材管理保留进度、重试和删除功能。
- 源文件分辨率与帧率单独显示，不再把下载现成原片另列为一种“下载 4K”流程。
- 修复非中文 Windows 的中文桌面快捷方式保存，使用显式 Unicode 系统接口。
- 未下载素材在调整其他设置后仍不能误点应用。

## 下载与更新

下载 **codex-arknights-0.12.4-windows-x64.zip** 并完整解压。保存工作、正常退出客户端，备份安装目录 `.local` 后运行新包 `安装.cmd` 安装到原目录。个人素材和配置会保留。

进入壁纸中心，选中视频后直接点击 **下载原片**。官方动态的本机生成 4K 仍需配置可选的 Python、NVIDIA CUDA、FFmpeg 和模型；自动安装整套 AI 环境尚未加入。
