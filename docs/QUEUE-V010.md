# 队列管理 · 0.10.0

更新日期：2026-10-25。

## 使用流程

- 壁纸 → 播放队列：左侧“我的队列”常驻显示全部队列、壁纸数量和播放状态。查看队列不切换当前播放。
- “新建队列”立即创建独立队列，空队列也保存。名称、排序、时长、循环、共用背景、条目构图均自动保存。原有队列按原 ID 迁移，默认保持循环播放。
- 队列内“添加壁纸”：回到总览，上方持续显示目标名称和本次添加数量。可以在不同分类中连续添加；具体时装／完整壁纸卡片提供快捷加入。完成后返回原队列。
- 普通“加入播放队列”：先选目标，可选已有队列或新建。默认选中上次添加的目标，名称始终可见，不按最新创建时间偷偷改目标。
- 干员组合采用目标队列的共用背景及背景构图；保留条目的人物构图。完整静态壁纸与动态视频独立播放。
- 播放控制栏标明实际正在播放的队列。“播放此队列”或“从头播放此队列”才更换／重启播放；上一项、下一项、暂停控制栏中标明的播放队列。
- 默认静态 60 秒、动态全部动作顺序播放 2 遍。循环默认开启；关闭后最后一项完成时暂停并保留画面，继续播放会从头开始。
- “最近使用”按最近添加／开始播放时间排序。删除队列不删素材，支持撤销本次打开期间最近一次删除。此次没有实现跨重启回收站或完整编辑版本历史。

## 保存与播放

每个队列是独立文档，以稳定 ID 保存。修改按队列追踪，合并短时间内的输入，串行写入；旧保存结果不能覆盖更新的草稿。失败时保留内存修改并显示重试入口。桌面端等待服务端本地写入确认后才显示“已自动保存”。尚未保存成功时直接结束整个应用，不能保证恢复内存中的修改。

非活动队列可以保存尚未选择背景的干员组合，开始播放前要求选择背景。移除当前播放队列或将其清空时，保留当前壁纸为单张播放。删除当前条目则衔接后续仍存在的条目。

播放条目 ID 与素材 ID 分离，同一壁纸可以在队列中出现多次。插入、排序、改名、时间调整、构图调整和编辑其他队列均不重置当前视频时间；结构变化只重新预载后继条目。仍使用两个视频解码器，保留原有首帧就绪后渐变机制。

## 验证

- `node --test tests/*.test.mjs`：配置边界、旧配置迁移、未完成队列、非活动队列编辑、4K 素材索引、HTTP 保存等。
- `scripts/queue-usability-check.mjs`：真实浏览器多队列创建、连续添加、指定目标、刷新恢复、删除撤销、排序；模拟写入失败及并发编辑；真实 4K 视频编辑时的解码器、时间、动作保持；关闭循环后停止。
- `scripts/wallpaper-surfaces-check.mjs`：桌面结构隔离测试，保存确认、调校同步、导航、退出和原生输入框保持。
- 测试使用独立配置目录，实际用户队列不写入测试数据。结果在 `test-results/queue-usability.json`、`test-results/wallpaper-surfaces-results.json`。
