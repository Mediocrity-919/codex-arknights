# Codex Arknights 0.12.3 · Windows Beta

免费、非盈利的社区桌面伴随程序。

## 本次修复

- 邀月接入单独的按需下载源：源文件为 3840 × 2160、60 fps，约 710 MiB。不随安装包分发，也无需在用户电脑生成 4K。
- 修复新安装环境中动态干员职业和星级元数据缺失，八职业筛选不再误显示为空。
- 壁纸详情明确提供“下载 4K 视频”；资源中心区分已是 4K 的源视频、可选本机生成的 4K，以及尚无在线来源的本地素材。
- 官方动态皮肤目前提供原片下载；未配置超分环境时显示配置入口，避免将本机生成误写成在线下载。
- 持续传输的大视频不再被 90 秒总时限中断，改为检测连接及长时间无数据；取消、断点续传和 SHA-256 校验保留。
- 添加全新 Windows 云端验收，覆盖安装、卸载、快捷方式、启动器、浏览、构图、队列、下载与资源管理。

## 下载与更新

下载 **codex-arknights-0.12.3-windows-x64.zip** 并完整解压。保存工作、正常退出客户端，备份安装目录 `.local` 后运行新包 `安装.cmd` 安装到原目录。个人素材和配置会保留。

更新后打开壁纸中心 → 动态壁纸 → 背景 → 邀月 → **下载 4K 视频** → **下载 4K 原片（60 帧）**。下载完成后应用即可。

邀月也可从[可选素材 Release](https://github.com/Mediocrity-919/codex-arknights/releases/tag/wallpapers-v1)手动下载。其余最初自备的视频尚无在线来源时会明确显示状态；官方原片仍可按需获取。

包内包含启动器和 Node 运行环境；请使用完整包，不要只复制 EXE。发布包不包含本地素材库。
