# Codex Arknights 0.12.5 · Windows Beta

免费、非盈利的社区桌面伴随程序。

本版修复英文等非中文 Windows 对中文快捷方式读取为空的问题。安装、升级、绑定原入口、恢复和卸载均统一使用 Unicode 系统接口；已被用户改动的快捷方式仍会保留。

保留 0.12.4 的四段原片独立下载，以及“下载原片”和“本机生成 4K”两个独立入口。四段原片及校验值见[可选素材](https://github.com/Mediocrity-919/codex-arknights/releases/tag/wallpapers-v1)。

下载 **codex-arknights-0.12.5-windows-x64.zip** 并完整解压。保存工作、正常退出客户端，备份安装目录 `.local` 后运行新包 `安装.cmd` 安装到原目录。个人素材和配置会保留。

普通图片、MP4 和四段现成原片下载不需要 Python。官方动态的本机生成 4K 仍使用可选的 Python、NVIDIA CUDA、FFmpeg 和模型；自动安装整套 AI 环境尚未加入。
