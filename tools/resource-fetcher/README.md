# 按需资源获取

资源中心使用 `resources/catalog.json` 中的目录快照和 `src/resource-manager.mjs` 获取单张图片或一套动态皮肤。基于 `背景资源获取.md` 记录的本机原图与官方动态采集流程整理；不依赖原 `.local` 缓存或本机盘符。Node 内置网络与文件接口即可下载普通图片和 MP4，无需 Python。

- 原片：低并发下载、进度、分段续传、自动重试入口、长度/哈希校验；中断后不会自动重新联网，用户点击重试继续。
- HLS：读取已收录的公开播放列表，下载其分段后由用户配置的 FFmpeg 无损封装。暂不支持加密、直播或未知播放列表结构。
- 4K：保留原片，再单独调用可选 AI 工具生成；不是从服务器下载官方原生 4K。取消任务会结束本任务的子进程，已完成原片保留。
- 删除：只处理目录中该壁纸对应的文件，先显示数量、大小与引用，正在使用的素材禁止删除；不会删除整个素材目录。
- 远端 URL 只取自目录快照并按域名校验，不接受用户传入的任意下载地址。来源或签名变化导致失败时，应更新目录；不会绕过站点访问限制。

## 可选 AI 环境

当前适配器延用本机集合使用的 `realesr-animevideov3-x2` 权重与 CUDA 推理方案。需要 Windows 上可用的 Python、NumPy、PyTorch CUDA、FFmpeg，以及用户自行取得并确认许可的 `.bin` 和 `.param` 模型文件。模型、PyTorch 和 FFmpeg 不进入源码包，也不会在普通启动时自动安装。

配置方法：运行 `scripts/Configure-Resource-Tools.ps1 -PythonPath <python.exe> -FfmpegPath <ffmpeg.exe> -ModelDirectory <模型目录>`，然后重启主题助手。只配置 FFmpeg 也可以启用 HLS 原片下载。工具会验证程序可运行、CUDA 可用和模型存在，设置仅存于该安装目录的 `.local/runtime.json`。

`upscale_one.py` 每次只处理一段视频，逐帧输出进度；整套动作由资源管理器依序调度。完整画幅缩放/补边到 1920×1080，再由同一 x2 模型生成 3840×2160，原帧率和音轨保持。此适配器目前需要 NVIDIA CUDA；无 CUDA 的设备请使用原片。

## 更新目录

维护者可在完整素材工作区运行 `node scripts/export-resource-catalog.mjs`，从本地已校验清单提取不含个人状态的元数据。这个命令不会下载资源。公开目录是快照，不承诺覆盖后续新增干员或时装。

最初的批量采集、资料对比与试验脚本仍在开发工作区 `.local`，不应原样打包：其中包含本机路径、缓存和批量行为。用户日常按需下载通过正式资源管理器完成。上游来源与历史流程见仓库根目录的 `背景资源获取.md`。
